O CineJoy Web é um projeto web desenvolvido com React e Next.js no frontend, integrado a uma API em C# e a um banco de dados SQL Server. A estrutura do frontend está organizada na pasta frontend, onde o Next.js gerencia as rotas enquanto o padrão MVVM é utilizado para separar a interface e os estilos (ui), as chamadas HTTP e os dados (data), e as conexões entre as telas e a lógica (viewmodel). A API, localizada em Back-end/Api, disponibiliza rotas e operações em Controllers, define as estruturas de dados em Models e gerencia a persistência no banco em Data, retornando respostas em JSON para a aplicação React. Na parte de banco de dados, contida em Back-end/database, estão os scripts para o SQL Server hospedado no servidor Regulus. Para o funcionamento completo do ambiente, são necessários Node.js, npm e o SDK do .NET 8 ou compatível, sendo exigido o uso da VPN institucional para conexões realizadas fora do Cotuca. Por fim, as credenciais do banco de dados são configuradas localmente para não serem expostas no Git, as tabelas do sistema já se encontram previamente criadas e as operações de pagamento do site são apenas simuladas, sem cobranças reais.
